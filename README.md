# RippleTrace · 俯拍水纹台

在水面俯拍原照上设置中心、内外半径和图尺。每个整数半径步回到最近一个源像素，角度从向右的0°顺时针计，向下为90°。保留真实原图点读、当前径向原样本和最亮位置。按角度图量每5°的原照片最亮半径。超出原图的位置没有读数。

在“标明纹点”模式可保存同一明纹上的标点和每点最大像素差。拟合会读取原照 RGB，排除任一通道恰为 0 或 255 的点，在当前内/外半径范围内寻找原图整数圆心与最小二乘拟合半径；采用点必须逐点满足半径差限差，并覆盖以建议圆心划分的四个象限（轴上点可用但不计入象限）。建议结果可一键采用并重新拉取原片图和径向图；之后点读任一标点会返回原 RGB、是否采用、有符号半径差和绝对半径差。

使用注明合成的练习或上传单帧 PNG、JPEG、TIFF、BMP、WebP。现有测量能保存重开，下载含原照的ZIP、实际源点CSV或PNG校样，或把原照送入图像准备。

`docker compose up --build` 后访问 `http://127.0.0.1:19923/`。只监听本机，测量卷及准备项目持久保存。
