# RippleTrace · 俯拍水纹台

在水面俯拍原照上设置中心、内外半径和图尺。每个整数半径步回到最近一个源像素，角度从向右的0°顺时针计，向下为90°。保留真实原图点读、当前径向原样本和最亮位置。按角度图量每5°的原照片最亮半径；也可在径向剖面图上确认一个起步半径，从当前方向顺时针每5°跟踪同一条局部亮纹，最多90°。跟踪链上的三个源点只要任一 RGB 通道为 0 或 255，该方向即留空；峰点还必须比径向前后两个彼此不同的实际源像素都亮。相邻方向半径差不超过 2 px，断点不跨越，至少连续得到三个后续方向才给出采用建议。采用后点按角度图，剖面和原片标记会定位到该方向跟踪链上的实际峰，未跟到的方向留空。超出原图的位置没有读数。

使用注明合成的练习或上传单帧 PNG、JPEG、TIFF、BMP、WebP。现有测量能保存重开，下载含原照的ZIP、实际源点CSV或PNG校样，或把原照送入图像准备。

`docker compose up --build` 后访问 `http://127.0.0.1:19923/`。只监听本机，测量卷及准备项目持久保存。
