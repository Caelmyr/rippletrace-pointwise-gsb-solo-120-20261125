# RippleTrace · 俯拍水纹台

在水面俯拍原照上设置中心、内外半径和图尺。每个整数半径步回到最近一个源像素，角度从向右的0°顺时针计，向下为90°。保留真实原图点读、当前径向原样本和最亮位置。按角度图量每5°的原照片最亮半径。超出原图的位置没有读数。

在当前径向样本上填建议波距范围与允许像素误差，可选出至少四个原片亮峰；每个峰连同两侧更暗邻点都是三个不同原像素，任一通道为0或255即不采信。相邻所选峰共用同一波距，最多一处按两倍波距核对并把中间缺峰留空。采用后按现有标尺给出毫米波距，径向图与PNG校样标出同样的源点；点选已采用峰会回到它的原片像素。

使用注明合成的练习或上传单帧 PNG、JPEG、TIFF、BMP、WebP。现有测量能保存重开，下载含原照的ZIP、实际源点CSV、峰表CSV或PNG校样，或把原照送入图像准备。

`docker compose up --build` 后访问 `http://127.0.0.1:19923/`。只监听本机，测量卷及准备项目持久保存。
